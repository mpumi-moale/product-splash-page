# ✨ Scrimbafy Me

A clean, responsive **product splash page** for **Scrimbafy.me** — a fictional service that turns your picture into an iconic Scrimba-style avatar.

> A simple frontend project focused on layout, responsive design, typography, and CSS styling.


## 🛠️ Built With

- HTML5
- CSS3
- Responsive Design
- Flexbox
- Google Fonts

## ✨ Features

- Responsive split-screen layout
- Modern landing page design
- Product-focused hero section
- Image upload form
- Responsive typography
- Mobile-friendly layout
- Custom CSS styling and hover states

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/mpumi-moale/product-splash-page.git
```

Navigate into the project:

```bash
cd product-splash-page
```

Then open `index.html` in your browser.

No dependencies or build tools are required.
